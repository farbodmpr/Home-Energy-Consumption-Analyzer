
# Home Energy Consumption Analyzer

## Overview
A Python-based application that analyzes household electricity consumption and estimates monthly electricity costs.

## Features
- Register up to five electrical devices.
- Calculate daily energy consumption.
- Estimate monthly energy consumption.
- Calculate monthly electricity costs.
- Classify devices by energy consumption level.
- Identify the highest and lowest energy consumers.
- Sort device names alphabetically.
- Search for registered devices.
- Validate user inputs.

## Technologies Used
- Python 3
- Lists
- Loops
- Conditional Statements
- String Methods
- Mathematical Operations

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python main.py
```
